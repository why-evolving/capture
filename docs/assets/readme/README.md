# README 展示资源 / Showcase assets

这些资源仅用于项目介绍，不是应用运行依赖。

| 文件 | 来源 |
| --- | --- |
| `hero.svg` | 为本项目绘制的原创矢量封面。裁切框图形延续 `scripts/make-icon.swift` 的几何设计；卡片为装饰插画，不代表额外应用功能。无外部图片、字体文件或脚本 |
| `editor.png` | v0.6.2 应用自身的编辑器视图，使用 `SampleImage.make` 生成的示例和示例箭头标注 |
| `presets.png` | v0.6.2 应用自身的预设管理界面，使用同一生成示例 |
| `recording.png` | v0.6.2 应用自身的录屏配置视图。未录制桌面或环境麦克风 |

PNG 保留原始像素及必要色彩信息，移除文字、时间与其他附加元数据。不包含真实聊天、第三方应用截图、私人目录、设备名称或个人媒体。图中中文文案来自应用示例与控件，英文 README 不表示应用已经完整英文化。

Images show the real v0.6.2 UI with app-generated fixtures. No desktop capture or ambient microphone was used. PNG pixel data is unchanged; optional metadata has been removed. The hero is original vector artwork, not an additional UI screen.
