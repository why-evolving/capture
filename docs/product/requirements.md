# 产品需求

| ID | 能力 | 验收要求 |
| --- | --- | --- |
| CAP-01 | 截图 | 快捷键呼出区域/窗口/全屏；取消不修改剪贴板 |
| CAP-02 | 可调选区 | 选择前冻结；框内移动、边角缩放、回车确认；可切快速模式 |
| CAP-03 | 截后操作 | 成品复制后显示缩略图，可保存、编辑、置顶 |
| EDIT-01 | 编辑 | 标注、遮挡、裁剪与撤销重做；原图不可变 |
| STYLE-01 | 美化 | 背景、留白、圆角、阴影和窗口装饰 |
| PRE-01 | 预设 | 命名、预览、默认及自动应用；当前编辑独立 |
| OUT-01 | 清晰输出 | 导出不使用预览尺寸；源像素100%不重采样 |
| LIB-01 | 本地资料 | 可选历史、项目与恢复，删除有明确边界 |
| TOOL-01 | 辅助工具 | OCR、滚动截图、拼图与置顶，失败可恢复 |
| REC-01 | 录制 | 区域/窗口/全屏、独立快捷键和快速/调整选区 |
| REC-02 | 音画 | 双音源独立、暂停继续、时长剔除及MP4输出 |
| PRIV-01 | 隐私 | 本机处理、明确授权；不自动上传或采集环境麦克风 |

分发版必须遵守LICENSE和最小平台声明；尚未支持的格式、设备和编辑能力不通过虚假按钮表示已实现。
