# 技术结构

Swift Package包含CaptureCore和Capture。前者实现模型、验证、像素处理与格式；后者实现SwiftUI/AppKit、系统授权及工作流。没有外部Swift包依赖。

原图不可变，坐标使用原图左上角归一化，导出独立于预览。复制、保存、拖放使用相同成品渲染链。IO/渲染/编码在后台，旧任务不能覆盖新状态。

系统采集通过ScreenCaptureKit；麦克风按系统能力使用平台API。录屏增量写入，共同host时钟并剔除暂停时长，双音源实际混为可播放音轨。失败保留可恢复源，外部路径、尺寸、版本、数量及软链均需校验。

偏好设置、截图历史、预设和录屏会话在本机应用支持目录。默认预设、本次采集样式与当前编辑互不覆盖；旧设置向后兼容。

签名配置属于开发者本机，不在源码或CI中传递。公开默认应用ID为local.capture.app；需要稳定安装位置以保持授权及登录项语义。二进制分发前映射编译路径并在签名前去除调试映射。
