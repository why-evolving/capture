# 安装与分发

当前源码声明最低macOS14，面向Apple芯片Mac。安装包需来自可信发布者，解压并将Capture.app放入固定的应用程序位置。首次启动按系统提示授予屏幕录制权限，需要麦克风时再授权麦克风。

本地签名不等于Apple Developer ID及公证。未经公证的可信应用可能需要在尝试打开后，从系统设置的隐私与安全性选择仍要打开；不要关闭系统防护。受组织管理的设备可能限制安装。

生成安装包使用scripts/package.py，检查实际可执行文件、签名和解压后完整性。包内只包含应用、LICENSE、NOTICE、许可说明、来源说明和安装说明；不加入个人数据、日志、环境配置、原始验收或私钥。

分发受AGPL覆盖的程序须按LICENSE提供对应完整源码，保留许可/版权通知并说明修改；修改版网络交互还须满足第13条。允许商业使用及收费出售，不另加商业限制。源码下载须对应实际二进制版本。维护者未明确批准前，不公开仓库或发布安装包。
