# 界面与交互

使用原生Mac窗口及简洁浅色控件，清晰标明主操作。键盘、焦点、可访问性及减少动态效果应可用。

1. 欢迎页说明采集时机、系统授权和示例入口。
2. 框选先冻结画面；尺寸提示、边角手柄与浮条就近排列。取消和确认语义明确。
3. 截后缩略图下方放复制/保存/编辑等操作，菜单展开时暂停消失计时。
4. 编辑器按背景、标注、布局、效果、导出组织；预览与导出像素语义独立。
5. 预设区区分应用当前与设为默认，删除/覆盖明确确认。
6. 录屏浮条就地切模式、音源、画质和倒计时，更多选项逐步展开。调整模式松手保留选框，框内移动、八手柄缩放，回车开始。
7. 倒计时可取消或返回调整；录制时浮条提供暂停/继续和停止。结束后预览与另存，关闭保留本地作品。
8. 加载、权限拒绝、保存失败和取消应提供准确、可恢复的反馈，不伪装成功。
